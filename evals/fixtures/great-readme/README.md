# greet

Print a friendly greeting from your terminal: one shell script, no dependencies.

[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE) [![CI](https://img.shields.io/badge/CI-passing-green)](#)

<p align="center"><img src="docs/demo.gif" alt="Running ./greet.sh World prints Hello, World!" width="700"></p>

## Quickstart

```bash
git clone https://github.com/example/greet.git && cd greet
./greet.sh World
```

## How is this different?

| | greet | figlet | cowsay |
|---|---|---|---|
| Dependencies | none | C build | Perl |
| Output | one line | ASCII art | ASCII cow |
| Best for | scripts and CI logs | banners | fun |
